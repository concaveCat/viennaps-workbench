# 材料与多层结构：等待用户验收

候选地址：http://127.0.0.1:8768/

本轮到此停止。你只需检查配置与操作是否符合你的需要，不需检查代码、数值误差或工艺物理。

## 你可以试这三件事

1. **选择材料**：在二维项目中改变基底和某一层的材料，调整厚度，点击“生成结构预览”。确认材料列表、名称、单位和结果图例容易理解。
2. **编辑多层**：添加、复制、上下移动、删除层；指定薄膜/掩膜角色。确认上下顺序、厚度输入，以及最顶层开口的设置符合你的操作习惯。
3. **查看和保存**：切换到三维，选择顶层圆孔图案，预览后旋转和打开正交截面；保存项目、重新打开或导出项目 JSON。确认你能独立完成这个流程。

默认示例是 Si 基底、0.6 µm SiO2、0.6 µm Si3N4 掩膜。最顶层为掩膜时可设置开口。添加顶层薄膜使原开口失去作用目标时，界面会关闭开口并提示，不修改已有层的材料与角色。

目前可选 13 种材料：Mask、Si、SiO2、Si3N4、SiN、PolySi、SiGe、Al2O3、HfO2、TiN、W、Cu、PMMA。

材料身份和薄膜/掩膜角色分别设置。当前通用模型会保护掩膜材料；同种材料同时作为受保护掩膜和非掩膜时会给出明确错误。选择材料不会自动填入化学反应参数或改变全局速率。

本轮新材料/多层结构使用已验证 CPU 路径。按材料设置不同速率、定向刻蚀和后续功能尚未开始，等你完成这次验收后再推进。
