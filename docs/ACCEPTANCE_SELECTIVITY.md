# 第3轮：按材料刻蚀速率验收

状态：自动验收通过。用户已通过材料与多层结构阶段并授权继续，本轮完成材料速率和选择比显示。

入口：http://127.0.0.1:8769/ 。固定目录 `/root/viennaps-workbench-selectivity`，启动/状态/停止使用该目录下的 `scripts/start.sh`、`scripts/status.sh`、`scripts/stop.sh`。

## 本轮功能

- 二维、三维的各向同性与单粒子刻蚀支持按材料填写速率。
- 显式材料行优先，未列出材料采用默认速率。零表示保护；掩膜可设置非零速率；同材料的所有区域共用速率。
- 默认速率为零、表中存在非零速率时仍调用 ViennaPS。全部为零时为 no-op；单粒子需要运动时才使用具体射线引擎和种子。
- 选择比显示为参考材料速率/本材料速率；分母零时显示保护/∞，0/0显示未定义。参考材料不参与仿真哈希。
- 保存、重开、JSON导出、重放支持新增格式4。旧1/2/3格式保持兼容。
- 三维动态材料显隐支持格式4，历史三维重载修复保留。
