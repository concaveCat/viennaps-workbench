# P0 acceptance specification

All distances use micrometers. Evidence is saved under `var/probes/` during P0 and under `var/runs/<runId>/evidence/` during P5; the index is `var/acceptance/evidence-index.json`. Numeric tolerances here are application acceptance thresholds, not ViennaPS guarantees.
